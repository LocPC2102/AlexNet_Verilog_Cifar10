## DESIGN AND IMPLEMENTATION OF AN ALEXNET-BASED AI ACCELERATOR ON FPGA

---

Detailed project report: [AlexNet CIFAR-10 Project Report](https://github.com/LocPC2102/AlexNet_Verilog_Cifar10/blob/main/reports/alexnet_cifar10_report.md)

### INTRODUCTION
An end-to-end FPGA implementation of an AlexNet-based CNN for CIFAR-10
image classification, covering the workflow from model development
and INT8 quantization to Verilog RTL implementation and Vivado
verification.

---

### OVERVIEW
This project implements a lightweight AlexNet-based CNN for CIFAR-10 and explores its deployment as a hardware accelerator using Verilog RTL. The project covers:
**PyTorch Training → Calibration → INT8 Quantization → Parameter Export → Integer Reference Model → Verilog RTL → Vivado Verification**
